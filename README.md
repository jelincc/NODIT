# Nodit Console — Overview Redesign

Lambda256 Product Designer 채용 과제 제출물입니다.
Nodit Console의 Overview 화면(신규 가입 직후, 사용량 0 상태)을 정보 위계와 온보딩 경험 중심으로 재구성했습니다.

**Live prototype:** https://jelincc.github.io/NODIT/

## 개선 포인트

1. 프로모션 배너 2개를 히어로 위치에서 보조 컬럼의 소형 카드로 축소
2. 플랜·사용량·요청수를 상단 요약 스트립으로 끌어올려 스크롤 없이 확인 가능
3. 값이 0인 플랫라인 차트를 걷어내고 "Getting Started" 체크리스트로 대체
4. 업그레이드 CTA를 3곳 → 목적별 1곳으로 통합

## 인터랙션

- Getting Started 체크리스트 항목 클릭 → 완료 상태 토글
- Usage Detail의 Elastic / Dedicated 탭 전환
- Auto-Scaling 스위치 토글
